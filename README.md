The badges this year were created in EasyEDA Pro (https://pro.easyeda.com), but public sharing on the Pro version is cumbersome and requires an approval process that I apparently have failed to pass, so this is an export that you can import into your own project.  I'll likely switch over to KiCad for next year so we're on an open platform.

The export and schematic PDF contain the designs for the standard badge, supporter badge, supporter badge keyboard, and the DIY kit badge.
